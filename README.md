# Vaibhav Mahajan Portfolio

This folder contains a static portfolio site tailored for job applications that value:

- strong backend and system thinking
- polished UI/UX presentation
- project storytelling
- fast deployment as a sharable portfolio link

## Files

- `index.html`
- `styles.css`
- `script.js`

## Quick deploy options

1. GitHub Pages
   Upload these files to a GitHub repository and enable Pages from the repository settings.
2. Netlify
   Drag and drop this folder into Netlify Drop.
3. Vercel
   Import the folder as a static site project.

## Customization ideas

- add project screenshots
- attach a downloadable resume link
- replace placeholder role-targeted copy as your stack grows
- add real project repository links when they are ready
